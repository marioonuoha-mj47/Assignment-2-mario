# Personal Portfolio Site

Portfolio built for INFR3120 Assignment 2 using Node.js, Express, and EJS.

Live site: YOUR_RENDER_URL

## Features
- Home, About, Projects and Contact pages
- EJS layout using header and footer partials
- Bootstrap 5 and Font Awesome

## Run locally
npm install
npm start
Then open http://localhost:3000
